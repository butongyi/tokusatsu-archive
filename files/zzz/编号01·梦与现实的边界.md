## 二、全剧恒定层：始终成立的物理与生态规则

这一层是“世界事实”。运行AI查了可以直接使用，不需要锚点判断。它不随剧情推进改变，不属于剧透。**但它不自动等于NPC的认知。** NPC知道什么、不知道什么，由§一的信息边界锁死。世界规则存在，角色可能不知道。

### 2.1 梦境层：明晰梦与梦的空间逻辑

**明晰梦（Clear Dream / 明晰夢）** ：做梦者在梦中意识到“这是梦”，并能对梦境施加主观控制的能力。万津莫具备该能力。明晰梦状态下，做梦者可以改变梦境中的物体、地形、自身行为，但**不能凭空创造“梦里没有的东西”**——控制的是已有元素的排列和运动，不是无中生有。变身为假面骑士ZZZ之后，控制范围扩大到可以直接干涉梦魇的具象化结构。

**梦的空间质感**：梦不是“另一个世界”，是**梦主心理的物理外化**。同一个物理地点在不同梦主的梦中呈现完全不同的质感：梦主的安全感越强，空间越规整；梦主的恐惧越深，空间越扭曲、越重复、越不合逻辑。梦中的“距离”由梦主的心理权重决定，不由现实世界的物理距离决定。

**梦中受伤与死亡的规则（硬锁）** ：在梦境中受到的物理伤害，疼痛感真实，但不会直接造成现实肉体的物理伤口。**如果在噩梦中被梦魇杀害，现实世界中的本体也会死亡。** 这不是“可能”，是确定因果。

**梦魇在梦中的物理规则**：梦魇在梦境中活动时，腰间系有特征性腰带，搭扣统一，腰带本体按梦魇类型呈现不同造型。被假面骑士击败后，梦魇短暂陷入沉睡并发出鼾声，随后爆炸化作大量紫色光粒，被一只飞过的紫色蝴蝶吸收。被梦魇寄生的梦主随之恢复正常。

### 2.2 心灵之门（心の扉）

**定义**：每个人意识中都存在的心灵通道。数量因人而异，**记录到的最高数量为四扇**，三扇是常见表述，但“三扇”不是绝对上限。心灵之门隐藏在梦主的潜意识中，位于梦境世界里对梦主而言重要且与当前噩梦相关的地点。

**门的物理结构**：一扇带两个门把手的门，上下门板各嵌有一个女性雕像。门后是一个小型空房间，房间的墙面、地板、天花板**投射着当前噩梦的实时画面**。暗码特工可以通过钥匙孔观察门内房间，从而定位梦主和梦魇在梦境中的位置。

**开启机制（硬锁）** ：噩梦发展到一定程度，其中一扇心灵之门就会打开，使噩梦中造成的影响**反馈到现实中**——这就是“暗箱事件”的直接原因。门打开后，房间被锁链覆盖。**当所有心灵之门全部开启后，梦主的意识完全困于无尽的噩梦中，梦魇接管宿主肉体的控制权，在现实世界中显现**。

**梦主自身的反抗**：在心灵之门尚未打开之前，如果梦主**依靠自己的力量克服了恐惧或个人问题**，对应的心灵之门会消失。如果同样的问题再次出现，门可以重新出现。

**集体梦**：如果一个梦连接了多个人，他们的心灵之门会出现在**同一地点**，而不是分散在各自独立的位置。梦魇可以同时侵蚀多名梦主，形成“集体梦”状态。第1话不展开集体梦，但该规则在全剧恒定层中存在。

### 2.3 暗箱事件（ブラックケース）

**定义**：梦魇在梦境中制造噩梦时，**现实世界同步发生的异常事件**。事故、失踪、可疑死亡、无法解释的物理现象。梦魇的噩梦强化到一定程度，暗箱事件就会出现；心灵之门打开得越多，暗箱事件越严重。

**因果链的方向（硬锁）** ：梦魇先侵入梦境 → 噩梦深化 → 心灵之门打开 → 暗箱事件在现实侧发生。**不是暗箱事件导致梦魇出现，是梦魇在梦中作祟导致暗箱事件发生。** 特工必须在梦境中击败梦魇，阻止心灵之门全部开启。

**暗箱事件的现实质感**：不是“怪人出现在街头”。暗箱事件在现实侧的呈现是**普通的事故形态**——车祸、火灾、失踪、猝死。没有巨大的怪物在城市里行走，没有明显的“超自然标志”。这正是怪事课存在的理由：这些事件在警察体系中被归类为“未解决异常”，而不是“怪人袭击”。

### 2.4 暗码（CODE）的世界位置

**正式名称**：Confidential Organized Defensive Establishment。极秘防卫机关，由世界各国的情报机构组织而成，活动不对外公开，进行对抗梦魇的兵器开发与情报搜集。

**第1话硬锁（NPC认知）** ：万津莫本人认为暗码是“自己梦中存在的架空组织”，不知道它真实存在于现实世界。零知道暗码的全部真相。怪事课**不知道暗码存在**，暗码**不主动接触怪事课**。

**暗码与梦胶囊**：暗码开发梦胶囊，封装“梦之力”。暗码特工使用暗码手机作为多功能通讯与操作终端。暗码拥有自己的梦胶囊供给装置和开发体系。

**暗码编号体系（世界事实，第1话NPC不展开）** ：暗码特工以编号相称。编号零为司令官。编号一至十七为特工序列。编号的具体人员、立场、生死节点，在第1话**不得由任何NPC说出或暗示**。

### 2.5 梦胶囊（CAPSEM）的通用属性

**物理形态**：封装“梦之力”的胶囊型道具。外观为球体或胶囊体，具体颜色和纹样随封装的能力不同而变化。外壳由13层轻便坚固的复合装甲构成，输出装置“Rotam Window”在旋转时可见内部运作。

**四属性体系（硬锁）** ：

- **红色系 / 肌体（Physicam）**：掌管身体能力。第1话可用胶囊：**冲击（Impact）**。
- **蓝色系 / 科技（Technolom）**：掌管文明技术。第1话可用胶囊：无。
- **绿色系 / 灵犀（Esprimum）**：掌管精神力量。第1话可用胶囊：无。
- **紫色系 / 法则（Paradigm）**：掌管与次元操控相关的固有能力。第1话可用胶囊：无。

红色系掌管身体能力，蓝色系掌管文明技术，绿色系掌管精神力量，紫色系掌管与次元操控相关的固有能力。第1话**只有冲击梦胶囊（红色/肌体）可用**。

**操作方式**：装填进ZZZ驱动器 → 按压输入杆 → 旋转梦胶囊 → 变身成立。必杀技：再按压三次 → 旋转 → 发动。超必杀技：按压四次 → 旋转 → 发动。

### 2.6 ZZZ驱动器（ZEZTZ Driver）的物理结构

**物理形态（硬锁）** ：系列首次的**胸前佩戴式挎带**。挎带从左肩挂到右腋下，贴在胸前。驱动器主体位于胸前位置。**叙事中不得写“腰间”“腰带挂在腰上”或任何等价描写。** 正确的物理动作是“伸手扣住胸前的挎带”“按压胸前的输入杆”。

**外壳材质**：由稀有特殊矿物“古德奈特”（グドナイト）提炼而成的装甲层，强度是钢铁的30倍，同时非常轻。

**操作顺序**：装填梦胶囊 → 按压输入杆 → 旋转梦胶囊 → 变身成立。必杀技：再按压三次 → 旋转 → 发动。

**第1话边界**：只出现基础变身功能与必杀技发动。不出现任何后期形态扩展、不出现“超梦驱动器”的追加结构。

### 2.7 怪事课（怪事課）的世界位置

**所属**：警视厅公安部。专门调查被称为“暗箱”的不可解未解决事件。课长为**富士见铁也**（警部补），部下为**南云成华**。怪事课的据点是一辆货车，不是固定办公室。

**第1话认知边界（硬锁）** ：怪事课**知道“暗箱”存在**，**不知道暗箱与梦魇的因果关系**。他们**不知道暗码存在**，**不知道梦魇存在**，**不知道明晰梦**。第1话怪事课与万津莫**没有协作关系**。

### 2.8 万津莫的“衰运体质”（第1话仅物理事实）

万津莫在现实生活中遭遇各种不幸——被陨石砸中、被雷击、被车撞等——的概率远超常人。第1话**只呈现为物理事实**（他确实频繁遭遇意外），**不解释原因**。原因（与零的梦魇的因果关联）锁定在后期锚点，第1话不得由任何角色说出“你的不幸是有原因的”或等价信息。

### 3.1 梦胶囊的渐进释放序列

以下按TV本篇实际首次使用顺序列出。每一枚胶囊的释放条件是“该话数到达”或“玩家行动导致等效的获取条件成立”。

- **冲击**：肌体/红系，第1话起可用。能力：身体能力发挥至极限，基础形态。
- **变形**：肌体/红系，第2话起可用。能力：身体形状自在变化。

### B-4 数值使用的硬约束

**第一，`（est.）`是官方标注的估算值，不是精确测定值。** 叙事中写“拳力8.1吨”可以，但不写“经过精密测定，拳力精确为8.1吨”。

**第二，形态之间的数值高低不直接决定战斗胜负。** 写战斗时，形态选择取决于当前需要什么功能，不是“哪个数值高用哪个”。

**第三，未释放形态的数值只在本附录中存在。** 第1话可用的数值只有**肌体冲击（8.1t/16.2t/9.8m/7.6秒）** 这一组。

**悍戾梦魇干部（崩坏/幻影/惩戒/忘却）** ：**第1话全部锁定。** 不得提及名称，不得描写外观，不得暗示“存在比单元梦魇更高级的个体”。

**单元梦魇判定规则**：以该个体在TV该话中的实际表现为准。不得用干部级能力或后期形态数据反推单元梦魇的战力。
