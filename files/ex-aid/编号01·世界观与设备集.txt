# 第一部分：世界观与场景

## 一、基础规则与崩源体生态

### 1.1 崩源体病毒（Bugster Virus）

病毒进入人体，在脑内寄生，增殖。潜伏期不发作。感染者因压力导致免疫系统衰弱时，病毒开始增殖，游戏病发作。

发作的物理进程按顺序走，不跳跃：

1. **初期**：头晕、发热、咳嗽。症状和感冒一样，本人和周围人都不会觉得异常。患者可能自己吃点药，继续上班或上学。
2. **中期**：身体表面出现噪音流动。肉眼能看到皮肤下面有东西在动，像老电视的雪花噪点沿着血管走。用游戏观察仪（听诊器形状的探测设备）贴在皮肤上，可以听到持续的电子杂音。这个阶段，患者开始被CR接管。
3. **后期**：病毒夺取身体控制权。患者身体逐渐透明，从指尖开始，皮肤下面的结构变得可见，然后变淡。透明化不可逆，除非崩源体被分离并击破。完全透明时，患者消失。
4. **实体化**：病毒从患者体内分离出来，变成怪物。分离只能由Level 1形态的骑士执行。分离之后，患者身体仍然透明，必须击破分离出来的崩源体，透明化才会停止并逆转。

病毒不通过空气或接触在人与人之间传染。感染源头是被污染的游戏卡带或游戏设备。

### 1.2 崩源体生态

崩源体是从人体内分离出来的病毒聚合体，拥有独立行动能力。等级按战斗力划分：

- **Lv.1-2**：初始形态。对应单一游戏数据。外形和该游戏的头目角色一致。行为模式简单，按游戏逻辑行动。
- **Lv.3-5**：进化形态。能力扩展，可以同时使用多种攻击方式。
- **Lv.30+**【第19话起才出现】：第19话起战斗力跃升至此级别。可以夺取宿主身体实体化，不再依赖分离状态。
- **Lv.50**【第19话后·需锚点触发】：高阶完全体。拥有独立人格，可以对话、谈判、背叛。被击败后只要数据残存即可复活。复活后等级提升。
- **Lv.99+**【后期·第1话不可用】：最终形态。剧中仅Gamedeus达到此级别。

**完全体**的诞生条件：感染者压力达到峰值，崩源体夺取宿主存在并实体化。完全体不再需要宿主存活，拥有完整人格。Graphite、帕拉德、Poppy、天崎恋都属于完全体。

**复活特性**：被击败的崩源体，如果数据被回收（例如被Genm的Gashacon缺陷护罩回收），可以再度实体化。复活后等级通常高于死亡时。数据完全消灭则无法复活。

### 1.3 游戏领域

玩家驱动器展开的独立空间。展开瞬间，现实场景的物理表面被覆盖一层游戏视觉层：地面出现方格纹理，天空变成纯色或渐变，建筑物边缘出现像素描边。

游戏领域内的物理规则和现实一致——重力、碰撞、材质硬度不变。变化的是视觉表现和附加机制：

- **伤害数字**：攻击命中时，命中位置浮出白色或黄色的数字，数字大小对应伤害量。数字停留约一秒，然后淡出。
- **Hit演出**：每一次有效攻击，画面中弹出“Hit！”字样，字体是粗体，带描边。
- **VS显示**：骑士和崩源体对峙时，两者之间浮出“VS”标志，停留到一方移动或攻击。
- **武器按钮操作**：使用Gashacon武器时，武器侧面或握柄上出现彩色按钮图标，按对应按钮切换模式。切换时武器发出机械音。
- **道具箱**：领域内随机位置生成半透明的道具箱。打开后获得能量道具——恢复HP的、加速的、暂时无敌的。Ex-Aid拿到道具时说“アイテムゲット”（Item Get）。某些特定道具可以让Ex-Aid巨大化到46米。
- **场景切换**：玩家驱动器左侧有按钮，按下后可以将游戏领域内的所有人和物传送到另一个场景。切换时画面闪烁一次，音效是短促的电子音。

**手术限制**：只有Level 1形态可以在游戏领域内执行分离手术。Level 1是小体型形态，高度约181cm但视觉上呈三头身比例，动作灵活，专门用于从患者体内切除崩源体。Level 2及以上专用于与已经分离出来的崩源体战斗。用Level 2执行分离手术无效。

**适合者**：体内存在崩源体病毒抗体的人。抗体通过适合手术获得——向体内注入微量崩源体病毒，身体产生抗体后，可以安全使用玩家驱动器。没有抗体的人强行启动卡带，会立即感染游戏病。

## 二、核心势力与场景

### 2.1 CR（电脑救命中心）

位于圣都大学附属医院地下。入口在医院专用电梯里，按特定顺序按键才能抵达：B1按两次，1按两次，然后开门键和关门键同时按。电梯门打开时，外面是普通的走廊，灯光比医院上层更白、更冷。走廊尽头是一扇没有标识的门。

门后是主控室。空间比从外面看上去更大。正对门是一排监控屏幕，屏幕下方是一块控制面板——不是医疗仪器的平面触控板，是街机厅里那种控制台。左侧一根摇杆，右侧排列彩色按钮，红黄蓝绿，按钮表面有使用磨损的痕迹。面板边缘贴着几张手写标签。

主控室右侧是隔离病房。病房和主控室之间隔着玻璃墙。病床可以推到玻璃墙前，床上的患者面对监控屏幕。屏幕显示患者的实时身体数据：心率、体温、病毒增殖速率，以及一个全身扫描图像，图像上病毒活跃的区域用红色标记。

主控室左侧是医生观察室。观察室和隔离病房之间也隔着玻璃，医生站在观察室里可以看到病房内的全部动作。观察室里放着一台《DoReMiFa Beat》街机台，屏幕亮着，待机画面循环播放标题演示。街机台旁边是一张折叠椅和一张金属桌，桌上散着几张病历和一支笔。

出诊时，CR医生骑摩托车。摩托车白底黑纹，侧面印红色“AID”字样。车停在医院后门的专用车位，钥匙插在车上，随时可以出发。

### 2.2 幻梦集团

总部大楼在市中心，玻璃幕墙，大厅前台后面是一面显示公司logo的屏幕，logo循环旋转。电梯需要刷卡才能按楼层。

社长办公室在顶层。办公桌很大，桌面整洁，只有一台笔记本电脑和一个茶杯。办公桌旁边放着一张乒乓球桌，球桌标准尺寸，网架夹在中间，桌面上有两块球拍和一个白色小球。球桌的使用痕迹明显——边缘有磕碰，桌面有球印。

旧社屋在另一处街区，是一栋较矮的旧楼。外墙瓷砖有几块脱落，入口的卷帘门半开着。内部光线不足，走廊尽头的房间里有非法开发设备——原型卡带的测试台、数据线、散落的电路板。设备处于待机状态，指示灯间歇闪烁。

### 2.3 花家大我的闇诊所

前身是一家废弃医院。建筑外观没有招牌，入口的自动门坏了，需要手动推开。门轴发出摩擦声。

内部光线昏暗，大部分区域没有开灯。大我使用的房间原本是诊室，现在放着一张检查床、一台旧式扫描仪、一张桌子和一把椅子。桌上有一台笔记本电脑、几份病历、一个咖啡杯。杯子里的咖啡已经凉了，表面结了一层膜。扫描仪是从某处“借”来的，外壳有划痕，电源线用胶带缠过。

诊所没有护士，没有其他医生。大我独自在这里接诊、分析样本、进行交易。患者来的时候需要敲门，大我从里面开门，看一眼，然后侧身让开。

### 2.4 卫生省

极少直接展示内部。出现在画面里的时候，通常是新闻发布会——官员站在背景板前，背景板印有“MOH”标志，面前排着话筒。或者会议室里的显示器，屏幕上显示“MOH”标志和一行加密通讯提示。

## 三、历史线与当前状态

### 3.1 十六年前

檀黎斗以儿童永梦构想的游戏点子为原型，制作了“Mighty Action C”。永梦成为世界上第一位游戏病患者。从永梦体内取出的病毒，成为后来所有崩源体个体的起源。这件事在TV第1话时间点，只有黎斗和极少数人知道。永梦本人不知道。

### 3.2 零日事件（2011年）

十款原型卡带的缺陷爆发大规模病毒。大量人类数据消失，保存在卡带中。黎斗将罪责嫁祸给父亲檀正宗，自己就任幻梦集团第二代社长。日向恭太郎与镜灰马借此设立CR。这件事在TV第1话时间点，公众认知是“一场原因不明的集体事故”，真相被掩盖。

### 3.3 TV第1话时间点的社会面

游戏病处于极秘状态。公众不知道“崩源体”这个词，不知道CR的存在。偶尔有人“突然生病又突然康复”，被当作都市传说。医院里少数医生察觉到“最近这种怪病越来越多”，但没有正式渠道上报。

CR已经存在五年，处理过若干病例。飞彩在美国，尚未归国。大我在闇诊所活动，已经从黎斗手中购得玩家驱动器和砰砰射击卡带。贵利矢已从黎斗手中获得驱动器和爆走バイク卡带，正在调查零号患者的身份。

# 第二部分：设备、卡带与形态

## 一、变身器与核心道具

### 1.1 玩家驱动器（Gamer Driver）

荧光绿和荧光粉配色。腰带主体是长方形，左侧有两个卡带插槽，右侧没有插槽。正面中央有一个可拉动的黑色手柄。腰带内侧贴着皮肤的部分是软质材料，外侧是硬塑料。

使用流程，按物理顺序：

1. **插入卡带**。卡带插入内侧插槽时，卡带发出“ガシャット！”一声。驱动器随后发出音效：
   「ガシャット！レッツゲーム！メッチャゲーム！ムッチャゲーム！ワッチャネーム！？アイム ア カメンライダー！！」
   “Gashat！Let's Game！Metcha Game！Mutcha Game！Whatcha Name！？I'm a Kamen Rider！！”
   这一段对应Level 1变身程序。使用者身体被光覆盖，体型缩小，变成三头身形态。

2. **拉动手柄**。手柄拉开时发出“ガッシャーン！”一声，然后：
   「ガッシャーン！レベルアップ！」
   “Gachan！Level Up！”
   卡带名随后被念出，例如“マイティジャンプ！マイティキック！マイティマイティアクションX！”。使用者从Level 1变为Level 2，体型恢复标准人型，装甲展开。

3. **插入第二张卡带**（Level 3及以上）【第1话不可用】。手柄合回再打开，发出“ガッシャーン！レベルアップ！アイゲットユー！”音效，第二张卡带的武装模块在身体上展开。

4. **使用双重卡带**（Level XX）【第1话不可用】。两张卡带同时插入两个插槽，发出“ダブル・ガシャット！”然后“ガッシャーン！レベルアップ！”，变身为分裂形态。

使用条件：体内必须有崩源体病毒抗体。没有抗体的人拉动手柄时，手柄会卡住，驱动器发出短促的错误音，然后患者倒地，游戏病发作。

### 1.2 故障驱动器（Buggle Driver）

Genm专用。黑色主体，只插一张卡带。由Gashacon缺陷护罩和Bugster带扣组装而成。不需要适合者体质，病毒可以直接通过驱动器变身。变身音效：
「バグルアップ！デンジャー！デンジャー！デス・ザ・クライシス！デンジャラスゾンビ！」
“Buggle Up！Danger！Danger！Death the Crisis！Dangerous Zombie！”

### 1.3 故障驱动器Ⅱ（Buggle Driver Ⅱ）【第1话未出现·需锚点触发】

檀正宗、Poppy使用。内置特殊病毒传播机制。普通人类接触驱动器外壳会死，只有抗体者可安全使用。变身音效：
「ガチャン！レベルアップ！ライダークロニクル！…」
“Gachan！Level Up！Rider Chronicle！……”

### 1.4 原型卡带与始源卡带

**原型卡带（Proto Gashat）【第1话少数人持有】**：整体黑色，图案黑白。十款基础原型，零日事件的元凶。比正式版更强，但过度使用会反噬身体——大我的白发就是原型卡带后遗症的物理表现。原型卡带中保存着零日事件中消失者的数据。

**始源卡带（Origin Gashat）【后期·需锚点触发】**：原型卡带的α版，例如“原型非凡动作X始源”。开启的游戏领域具有抑制崩源体病毒的效果——领域内触碰到的崩源体等级会下降。变身后为Lv.0形态，拥有99条生命（续关机能）。

## 二、骑士卡带与形态

### 2.1 Ex-Aid

**动作玩家Lv.1**：181.0cm / 137.0kg。三头身比例，头部大，身体小。粉红、青绿、银色。拳7.7t / 踢11.5t / 跳30.5m / 跑100m 4.2s。Level 1的唯一职能是分离手术——用小型化的身体进入患者体内，把崩源体切出来。

## 三、武器与Ride-Player

### 3.1 Gashacon武器系列

- **破坏者（Ex-Aid / Genm）**：锤模式/剑模式。模式切换时发出机械音。
- **圣剑（Brave）**：炎模式/冰模式。切换时剑身变色，炎模式带火光，冰模式带冷气。
- **麦林枪（Snipe）**：手枪模式/步枪模式。切换时枪管伸长或缩短。
- **雀形弓（Lazer）**：弓模式。拉弦时发出张力声。
- **键盘剑（Ex-Aid Lv.XX / 无敌玩家）**【第1话不可用】：锯模式/炮模式/剑模式。三种模式，按键切换。
- **悖论刃枪（Para-DX）**【第1话不可用】：斧模式/枪模式。
- **缺陷护罩（Genm）**：激光枪模式/电锯模式。同时是变身器和数据回收装置——电锯模式接触崩源体残骸时，残骸被吸入护罩内部。

### 3.2 Ride-Player与《假面骑士编年史》【后期内容·第1话未发生】

Ride-Player是使用市贩版《假面骑士编年史》卡带变身的普通人，不是正式骑士。

变身流程：普通人将卡带插入市贩版驱动器，驱动器发出音效「エンター・ザ・ゲーム！ライディング・ジ・エンド！」“Enter the game！Riding the end！”。变身完成的同时，使用者体内被随机植入一个《编年史》内崩源体的病毒（帕拉德除外）。初期战斗力极低，攻击方式只有基础拳脚。

成长机制：Ride-Player可以通过夺取稀有角色（Ex-Aid、Snipe等）的Gashacon武器或骑士卡带来获得战斗优势。夺取方式不限——抢夺、交换、欺骗。

战败后果：Ride-Player战败后永久消灭。即使被治愈，只要不放弃卡带，就永久背负再次发病的风险。

## 附录：游戏病发作与分离手术的物理流程

这一节不写规则，只写一个病例从发作到治愈的全过程中，医生看到什么、听到什么、做什么。

**第一步：发现。** 患者在普通门诊或日常生活中出现头晕、发热、咳嗽。医生按常规感冒处理。如果医生有游戏观察仪（CR成员或持有设备的人），贴在患者胸口听——正常心跳声中混着电子杂音，像收音机没调准频道时的沙沙声。

**第二步：隔离。** 患者被送入CR隔离病房。病床推到玻璃墙前，监控屏幕上显示全身扫描图像。病毒活跃区域用红色标记，标记的范围每小时扩大一次。

**第三步：展开游戏领域。** 骑士站在隔离病房内或病房门口，插入卡带，拉动手柄。游戏领域以骑士为圆心展开，覆盖整个病房。病房的白色墙壁变成游戏场景的纹理，地面的瓷砖线变成方格。患者身体上的噪音流动变得可见，像一层抖动的像素覆盖在皮肤表面。

**第四步：分离。** 骑士变为Level 1。三头身的小型身体跳到患者身上，用手或武器接触噪音流动最密集的位置。接触点发出白光，然后崩源体的连接体从患者体内被拉出——一个巨大的、由数据和噪音构成的团块，形状不稳定，不断重组。Level 1的骑士攻击连接体，每一击都让连接体的结构松动。连接体碎裂后，崩源体怪人态从碎片中站起来。

**第五步：切除。** 骑士切换为Level 2或更高形态，与怪人态战斗。怪人被击破时，身体碎裂成像素块，像素块消散。患者身上的透明化在同一瞬间停止，已经开始透明的部位慢慢恢复原来的颜色。

**第六步：术后。** 患者躺在隔离病房的病床上，监控屏幕上的红色标记消失。医生在病历上写记录。骑士解除变身，腰带发出短促的结束音。
