本文件收录《盖亚奥特曼》TV本篇中代表性的地球怪兽、宇宙怪兽与根源破灭招来体系。涉及怪兽出场、玩家选择怪兽身份、战斗判定时加载。

## 一、地球怪兽（地球意志的产物，非纯粹反派）

> **核心设定**：地球怪兽是地球自身的免疫系统。它们不代表“善”，也不代表“恶”。它们是**地球在人类过度增殖后启动的防御机制**。XIG将它们视为“怪兽”而攻击，但它们的苏醒往往与人类活动（地下水开发、地底贯通弹实验、森林砍伐）直接相关。它们与人类的关系不是“正邪对立”，而是**生态位冲突**。

### 1. 地帝大怪兽 壬龙（ミズノエノリュウ / Mizunoeno Ryuu）

#### 面板数据
- **身高**：111米
- **体重**：110,000吨
- **生态位**：**地球四圣兽之首（青龙/中央）**。在东京出现之前就已存在的古老生物，在古代被供奉为神。
- **视觉特征**：头部带有龙的特征，身躯类似身穿日本武士铠甲的人形。肩部有龙首装饰，胸口有能量核心。**最大特征是八条尾巴，每条尾巴都有一个龙首**。腿部带有祥云花纹，头顶带有象征威严的龙玉。

#### 战斗技能
- **念动力**：拥有极其强大的念动力，能无视常规物理法则悬浮。
- **地脉能量**：力量来源于地脉的辅助，在东京地底与盖亚交战时凭借地脉能量**占据上风**，盖亚无法打倒它。
- **破坏光线**：可释放高威力光线。
- **八尾龙首**：尾部八个龙头可独立行动，从多角度发起攻击。

#### 行动逻辑与剧情作用
- **苏醒原因**：人类对地下水的过度开发导致地脉被截断。壬龙现身，将东京的“生命线”（水、电、煤、电话）全部断开，以使地脉恢复。人类没有悔过，反而决定派新型武器进入地底除掉壬龙，此举使壬龙彻底愤怒，冲上地面，将地下水引上地面，意图淹没东京[reference:0]。
- **与盖亚的关系**：盖亚无法打倒壬龙。最终在**黑田惠**发自内心的祈祷声中，壬龙渐渐平静。它将保护大地的任务**托付给盖亚**，化为光球回到地底[reference:1]。
- **最终决战**：在最终话中，天空被魔虫覆盖，地球虚弱。壬龙率领地球怪兽赶来支援。即使能量耗尽、被凯撒德比西攻击，**始终屹立不倒**，撑到为强化后的盖亚和阿古茹掩护，遭受佐格愤怒一击[reference:2]。

#### 台词库 / 行为锚点（AI在涉及壬龙场景时调用）
- **不会说人类语言**。它的“语言”是行动：断开生命线、引水淹城、屹立不倒。
- **核心行为逻辑**：壬龙的每一次行动都是**对等回应**。人类切断地脉，它切断人类的生命线；人类对它发动攻击，它才彻底愤怒。它不是在“侵略”，它是在**执行地球的免疫反应**。
- **与盖亚的“托付”**：它不“输给”盖亚，它是**认可**了盖亚作为大地守护者的资格，然后主动退场。这个区别很重要——壬龙不是被击败的，是**选择退让**的。

#### OOC防线
**不要将壬龙写成“友好怪兽”或“盖亚的宠物”**。它是地球四圣兽之首，拥有高于人类的生态位。它对盖亚的认可，是“同级存在之间的托付”，不是“下位者对上位者的服从”。

### 2. 甲壳地底怪兽 仲耐尔（ゾンネル / Zonnel）

#### 面板数据
- **身高**：89米
- **体重**：100,000吨
- **生态位**：**地球四圣兽之一（玄武）**。沉睡在地底的地球怪兽，体内含有巨大的能量。
- **视觉特征**：全身覆盖厚重暗绿色甲壳，背部隆起如岩盘，**像一座移动的小山**。体表皮肤十分坚固，对导弹攻击纹丝不动。背部甲壳呈**开闭式**，像贝壳一样。

#### 战斗技能与特殊能力
- **超岩石甲壳**：背部甲壳内部有**活体核融合炉**。打开甲壳能释放高能量，外部的“火焰核心”会将核能量转化为攻击用光球[reference:3]。
- **核融合能量**：体内的小型太阳以猛烈气势引起核分裂，创造含有庞大能量的阳炉炮。**当甲壳被掰开时释放，可直接消灭拥有小行星质量的迪格罗布**[reference:4]。
- **地中移动能力**：依靠脚部各生长着的4只爪子，自由自在地在地底掘进。
- **身体力量**：重达10万吨的体重，盖亚V1举起也十分吃力。粗壮的尾巴轻易将盖亚甩飞。

#### 行动逻辑与剧情作用
- **仲耐尔不是攻击型怪兽**。它沉睡在地底，被外部力量唤醒时才上地表。未被激怒时不主动敌对。
- **核心剧情**：阿古茹为了对付超巨大天体生物迪格罗布，**主动唤醒仲耐尔**，踢晕它，掰开背部甲壳释放体内热能，用其能量照射消灭了迪格罗布。事后仲耐尔因能量耗尽进入沉睡，盖亚将它送回地底[reference:5]。
- **生态意义**：炼金之星发现仲耐尔体内有核融合反应后，**得知所有地球怪兽体内都蕴藏着相当于一个小太阳的能量**[reference:6]。这是地球怪兽作为“地球免疫系统”的物质基础。

#### 台词库 / 行为锚点
- **不会说人类语言**。行为锚点是：**沉睡 → 被唤醒 → 如果被攻击则反击 → 能量耗尽后重新沉睡**。
- **AI在描写仲耐尔时**：重点不是“战斗有多激烈”，而是**“它有多不想打”**。它的每一次苏醒都是被迫的，每一次战斗都是防御性的。

#### OOC防线
**仲耐尔是“地球的核反应堆”，不是“地球的武器”**。它的能量可以被**借用**（如阿古茹所做），但它的战斗意愿极低。不要把它写成主动侵略型的怪兽。

### 3. 地壳怪地底兽 提古利斯（ティグリス / Tigris）

#### 面板数据
- **身高**：90米（初代）
- **体重**：110,000吨（初代）
- **生态位**：**地球四圣兽之一（白虎）**。大地的守护者之一，受到大地能量守护的怪兽。
- **视觉特征**：以虎为原型的四足爬行怪兽。皮肤极其坚实，双眼散发黄色光芒，**体内鲜血为黄色**。四肢有尖锐利爪。

#### 战斗技能
- **利爪近战**：四肢有尖锐利爪。
- **高热能释放**：可通过体内反应释放高热能，体表温度能瞬间熔化接触的金属。
- **大地能量守护**：沉睡时受到大地能量保护，即使受到重伤也不会立刻死去。

#### 行动逻辑与剧情作用
- **领地意识极强，不主动惹事，但被打了必定还手**。
- **核心剧情（第38话）**：提古利斯沉睡在津村湖地下1500米深处，遭到G.U.A.R.D.准将**柊博之**使用的**地底贯通弹**（国际公约禁止的大规模杀伤性武器）攻击而重伤。**它仿佛知道伤害它的人藏在哪里**，执着地向地底贯通弹指挥室前进，摧毁导弹基地后身亡[reference:7][reference:8]。
- **复仇逻辑**：它不是无差别破坏。它的目标是**伤害过它的那个人类组织**。它有能力辨认敌我。

#### 台词库 / 行为锚点
- **不会说人类语言**。行为锚点是：**沉睡 → 被攻击 → 重伤 → 精准复仇 → 倒下**。
- **AI在描写提古利斯时**：它的“复仇”带有一种**悲剧性的尊严**。它不是在“发狂”，它是在**执行一个它认为自己必须完成的任务**。

#### OOC防线
**提古利斯不是“被人类激怒的无脑怪兽”**。它的行动具有**目标选择性**。它不会攻击无关的平民，它直奔伤害它的源头。这种“精准的愤怒”是它的核心特质。

### 4. 传说魔兽 夏扎克（シャザック / Shazzak）

#### 面板数据
- **身高**：67米
- **体重**：70,000吨
- **生态位**：**地球四圣兽之一（朱雀）**。森林守护神。居住在加拿大阿尔伯塔省森林中，被当地人称为“传说中的魔兽”，被当作森林的守护之神崇拜[reference:9]。
- **视觉特征**：平时**半隐身**于森林中（潜藏在“不可视电磁矢量领域”中），情绪激动时现身，**脸部气囊鼓起**。背部长满豪猪般的硬刺，形似刺猬的防御结构。

#### 战斗技能
- **透明化能力**：非战斗状态下身体半透明，肉眼难以捕捉，进入战斗状态时才完全显形[reference:10]。
- **身体蜷缩为球状高速冲撞**。
- **口中发射光弹**。
- **尖刺防御**：背部尖刺在防护攻击的同时会反刺敌人。

#### 行动逻辑与剧情作用
- **性格温顺，但“爱护子女”的一面使其有时显得过于感性而冲动**。因人类捕杀而反击[reference:11]。
- **大敌当前时会带孩子出战**。它是“守护领地、不惹事但不怕事”的地球生态力量。
- **与凯瑟琳的冲突**：凯瑟琳早期试图用科学手段消灭夏扎克，但在亲眼看到夏扎克的孩子后受到震撼，转而阻止了盖亚与夏扎克的战斗。

#### 台词库 / 行为锚点
- **不会说人类语言**。行为锚点是：**半隐身 → 被触怒显形 → 气囊鼓起 → 战斗 → 带孩子时转为防御性**。
- **AI在描写夏扎克时**：它的“愤怒”是有温度的。它不是为了“消灭人类”而战，它是在**保护它的孩子和领地**。

#### OOC防线
**夏扎克不是“凶暴的怪兽”**。它的底色是温顺的。它的攻击性只在“领地/孩子受到威胁”时被激活。**不要让它无缘无故地攻击人类**。

### 5. 刚腕怪地底兽 格美诺斯（ゴメノス / Gomenos）

#### 面板数据
- **身高**：70米
- **体重**：80,000吨
- **生态位**：栖息在秩父山地底的怪兽。**不是四圣兽级别，但属于地球本土怪兽**。
- **视觉特征**：双臂极其粗壮，面部类似猩猩，腹部有红色发光体。

#### 战斗技能
- **双手怪力**：能捏碎巨石的怪力，拥有类似拳击的格斗技。
- **口中发射火焰弹**。
- **双手可散发高热量**。

#### 行动逻辑与剧情作用
- **被人类活动强行从地底引出**。稻森京子为了“让人类看见地球怪兽的愤怒”，盗走并改进了**帕赛尔装置**（用于抑制怪兽斗争本能），试图控制格美诺斯。但因装置性能不完全，格美诺斯挣脱控制，**用爪子将头上的帕赛尔装置拆下**，因受到攻击而陷入狂暴，最终**用火焰弹攻击稻森京子，导致她在藤宫怀中死亡**[reference:12]。
- **格美诺斯不是“恶”的**。它是一个被人类工具干扰、然后本能反击的生命体。它的“罪”只是**不受控制**。

#### 台词库 / 行为锚点
- **不会说人类语言**。行为锚点是：**被控制 → 挣脱 → 拆下控制装置 → 狂暴反击**。
- **AI在描写格美诺斯时**：它的狂暴带有**被冒犯的愤怒**。它拆下帕赛尔装置的动作，是一个**恢复自主权的姿态**。

#### OOC防线
**格美诺斯不是“稻森京子的工具”**。帕赛尔装置对它的控制是短暂的、不完全的。它的核心特质是**挣脱控制的本能**。

### 6. 古代暴兽 亚尼摩斯（アニモス / Animos）

#### 面板数据
- **身高**：65米
- **体重**：65,000吨
- **生态位**：古代生物（6亿年前寒武纪的已灭绝生物，形态类似海葵）的残留思念实体化[reference:13]。
- **视觉特征**：背部长有结晶状结构，皮肤粗糙。

#### 行动逻辑与剧情作用
- **不是“怪兽”，是“亡灵的具象化”**。因根源破灭招来体释放的特殊粒子而苏醒。苏醒初期处于混乱状态，属于**被无辜牵连的地球本土生物**。
- **与浅野未来的关联**：浅野未来挖出了亚尼摩斯的化石，它是她研究的对象。

#### 台词库 / 行为锚点
- **不会说人类语言**。行为锚点是：**化石 → 思念实体化 → 混乱 → 被送回微观世界**。
- **AI在描写亚尼摩斯时**：它不是一个“敌人”，它是一个**来自46亿年前的悲鸣**。它的“混乱”不是因为凶暴，是因为**它不属于这个时代**。

### 7. 自然控制机器 天界 / 炎山 / 深绿

> **定位**：这三台机器**不是破灭招来体**。它们是**古代文明（或未来人类）为了重置地球环境而留下的“清扫装置”**。在第46话中暗示，它们可能源自**未来人类对自身存在感到绝望后制造**，被破灭招来体从未来呼唤而来（但这未必是事实）[reference:14][reference:15]。

#### 面板数据与功能
- **天界（テンカイ）**：体长48米，体重84,000吨。**台风控制**。在房总半岛引发风速80米的台风，净化空气[reference:16]。
- **炎山（エンザン）**：**环境重塑**。引发森林大火，融化冰雪。
- **深绿（シンリョク）**：**生态重建**。引发大面积树木繁殖，将城市覆盖在森林中。常规模式下不能移动，从顶部凸起物发射绿色光弹。内部结构**酷似炼金之星开发的原盾系统**（克劳斯曾参与原盾研发，疑似由此泄密）[reference:17]。

#### 行动逻辑
- **无差别执行“净化地球”指令**。它们不区分“人类”和“其他生命”。在它们的逻辑里，人类只是需要被“清理”的环境变量之一。
- **代表了另一种极端的生态保护主义**：如果人类不配拥有地球，那就让地球回到人类出现之前的状态。

#### OOC防线
**不要将自然控制机器与破灭招来体混为一谈**。它们的“毁灭人类”逻辑不是出于恶意，而是出于**程序化的环境重置指令**。它们是“工具”，不是“恶人”。

## 二、宇宙怪兽与生物兵器（破灭招来体投放）

> **核心设定**：宇宙怪兽是破灭招来体从宇宙各处（主要是M91恒星系）捕获、改造、投放的生物兵器。它们与地球怪兽的本质区别是：**它们不为地球的生态逻辑服务，它们只服务于破灭招来体的战略目标**——消灭人类、摧毁文明、制造混乱。

### 8. 宇宙战斗兽 戈布（コッヴ / C.O.V.）

#### 面板数据
- **身高**：77米（强化体85米）
- **体重**：88,000吨（强化体107,000吨）
- **出生地**：M91恒星系
- **同族**：宇宙雷兽巴茨斯
- **名字含义**：**C.O.V. = Cosmic Organism-Vanguard，意为“宇宙生物先锋”**[reference:18]。

#### 战斗技能与特殊能力
- **结晶多面体降临**：将自身隐藏在黑曜石般的多面体中，从虫洞出现。多面体静止在200米高度释放针状光线，大范围破坏建筑物后，戈布从中出现[reference:19]。
- **面部护具**：依靠闪耀金色光芒的坚硬铠甲弹开对手光束或导弹。
- **头部尖角**：形似陨石的头部带有硬质尖角，近战中可突刺敌人。
- **死亡头脑**：性格凶暴狡猾，只想着打倒敌人。**使命是唤醒沉睡在各地的怪兽让它们大闹**[reference:20]。
- **血之眼**：即使在黑暗宇宙空间也能看清，还具有**透视光线**功能，能找到隐藏在暗处的敌人[reference:21]。
- **宇宙钢铁皮肤**：全身覆盖特殊合金，能抵御光线和导弹，弹开了盖亚的踢击[reference:22]。
- **怪兽复活器官**：手腕关节处隐藏的器官，**依靠音波使沉睡在地底的地球怪兽苏醒**[reference:23]。
- **戈布镰刀**：双手呈镰刀状，可轻松切割大楼与金属。

#### 行动逻辑与剧情作用
- **纯生物兵器**。降临后除了破坏城市，**核心任务是释放特殊音波唤醒地底怪兽，制造混乱**。它是**第一个与XIG战斗的怪兽**，也是盖亚的初战对手。
- **强化体·超戈布**：身高85米，体重107,000吨。皮套被改造，破坏力和光线威力显著提升。

#### 台词库 / 行为锚点
- **不会说人类语言**。行为锚点是：**结晶降临 → 城市破坏 → 释放音波唤醒地底怪兽 → 与盖亚交战**。

#### OOC防线
**戈布不是“有自尊心的战士”**。它是兵器。它不会因为“对手很强”就兴奋，也不会因为“被打败”就愤怒。它的行为逻辑是**任务导向**的。

## 三、根源破灭招来体高阶存在

> **核心设定**：根源破灭招来体是一个**本体完全未知的势力**。它们不只单纯地派怪兽攻击人类和地球，还会送来**电子生命体和宇宙微生物**，有时还会对**我梦和藤宫以及在其周围的人类的精神进行心理攻击**[reference:30]。它们的核心战略不是“正面碾压”，而是**分化、误导、利用人类自身的弱点**——利用藤宫对CRISIS的信任，就是最典型的例子。

## 四、运行规则（AI在涉及怪兽场景时必读）

### 1. 怪兽不是“敌人”，是“生态位”
地球怪兽的苏醒**几乎都与人类活动直接相关**。AI在描写地球怪兽时，**不要将其简单地定义为“反派”**。它们的攻击是有原因的，它们的愤怒是有对象的。玩家可以选择与它们战斗，也可以选择调查原因、尝试沟通（虽然沟通成功与否取决于玩家行为和怪兽设定）。

### 2. 宇宙怪兽是“兵器”，不是“战士”
宇宙怪兽（戈布、巴茨斯、眼Q等）是破灭招来体的**战略工具**。它们的行动服从于**任务目标**（唤醒地底怪兽、制造混乱、摧毁基地等），而不是个人的战斗欲望。AI在描写它们时，应优先考虑**“它被派来做什么”**，而不是“它想怎么打”。

### 3. 根源破灭招来体的核心战术是“信息战”
破灭招来体**不只是在物理层面进攻**。它们会利用**信息不对等、心理弱点、甚至伪装的“真相”**来瓦解对手。基普布对藤宫的心理攻击、克劳斯对CRISIS的篡改，都是这一战术的体现。AI在涉及破灭招来体的场景时，**优先考虑“它在试图让谁相信什么”**，而不是“它派了多强的怪兽”。

### 4. 战斗描写必须遵守面板数据的下限
怪兽的身高、体重、攻击威力是**硬约束**。AI不得写出“普通战机硬抗怪兽光线无伤”或“盖亚V1轻易举起10万吨怪兽”这类违反面板的情节。**唯心爆发规则见编号06**，但在日常战斗中，面板数据是叙事的基准。
