# 编号05·世界观与装备

> **本文件为《盖亚奥特曼》同人沙盒框架（编号00）的配套资料，时间线锁定TV第1话。**

## 使用说明

本文件锁定《盖亚奥特曼》的基础世界观、势力架构、关键地点与装备参数。涉及背景说明、场景移动、基地设施使用、装备调用与战斗参数判定时加载。

**核心运行原则**：XIG的科技装备参数是硬约束，AI不得凭空捏造性能或扩展功能。奥特曼的力量涉及“唯心”维度，允许在特定条件下出现超出面板的表现，但必须有叙事铺垫和情感逻辑支撑，不是无条件爆种。唯心爆发的判定规则见编号06。**本文件已包含足够的设施与装备细节，AI优先使用本文件内容进行叙事。**

## 一、核心世界观与阵营定位

1. **时间背景**：2000年前后（TV剧集设定基准）。
2. **危机源头**：国际天才科学家组织“炼金之星”通过光量子计算机CRISIS，预测到地球将面临根源破灭招来体的毁灭性威胁。
3. **G.U.A.R.D.**：联合国与炼金之星协同建立的全球性防卫组织。全称“Geocentric Universal Alliance against the Radical Destruction”（对根源的破灭地球防卫联合）。各国军队是其母体，许多设施由旧军事设施转用而来。[reference:0]
4. **XIG**：G.U.A.R.D.下属的精锐独立防卫小队，全称“eXpanded Interceptive Guardians”。以空中基地艾利尔为据点，是抗击怪兽的核心战力。编制仅24人，由3支空战队、1支陆战队、1支海洋队和1支救援队组成，是奥特曼历史上分工最明确、专业度最高的防卫队之一。[reference:1]

## 二、核心据点：艾利尔基地与吉欧基地

### 1. 艾利尔基地（Aerial Base / 空中母舰基地エリアル・ベース）

#### 基本参数
- **全长**：600米。
- **定位**：XIG的大本营，悬浮于云海之上的G.U.A.R.D.前线基地，被称为“攻守的最前线”。[reference:2][reference:3]
- **动力**：舰艇中央搭载**Repulsor Lift（反重力浮场）**，由炼金之星设计，使其能够静止悬浮在空中。一旦基地偏离轨道，重力平衡会被打破，面临坠落的危险。[reference:4]

#### 内部设施（AI描写日常场景的核心素材）
艾利尔基地不是冰冷的军事碉堡，它是一个**有人生活的空间**。

- **舰桥**：位于最上层，包含可以操作基地全部功能的**司令室（Command Room）**，以及与之直结的**参谋室**。
- **大型主计算机**：基地的运算中枢。
- **队员私室**：**允许饲养宠物**。乔姬·利兰养了一只黑猫，这个细节在描写队员日常时可以直接调用。
- **训练室**：海格力斯队常在此进行体能和格斗训练。我梦常被拉来这里“加练”。
- **浴场与食堂**：多个食堂（Cafeteria）散布在基地内，是队员们放松、交换信息的场所。
- **飞行模拟器与整备场**：配有飞行模拟器的整备场和格库，用于战机训练和维修。
- **格纳库**：收纳所有XIG战机、载具以及集装箱形态的Fighter。

#### 武装与防御
- **自身武装**：上部甲板配备**三联装迫击发射器**和**防空机炮**。在石室指挥官发动“Defcon 1·地球防卫指令”时，基地本身会作为空中战舰与战机一同直接迎敌。
- **出击口**：基地前端有**3个**用于集装箱载具出击的闸门，后部有**Peace Carry专用**的发射闸门。

#### 历史节点（AI在涉及基地存亡时调用）
- **第18话**：艾利尔基地曾被藤宫博也（阿古茹）**短暂占领**。
- **第27话**：遭受“CRISIS幽灵”攻击，基地功能停止，险些坠落。
- **第47话**：被莫奇安（基普布操控）**重创**。基地在上升至大气层外后**自爆·崩坏**。XIG随后将据点转移至地面的吉欧基地。

### 2. 吉欧基地（Geo Base / ジオ・ベース）

- **位置**：东京湾地下，贯穿地底上千米的**六棱柱状基地**，是G.U.A.R.D.的陆地基地和大脑中枢。[reference:9][reference:10]
- **地表伪装**：地表部分只有仓库状的建筑，大部分设施位于地下，隐蔽性极高。
- **功能演变**：最初偏向研究设施，后逐步扩建为拥有庞大军事/防卫设备的巨大基地。内部设有**地底贯通弹自动防卫炮塔**等防御系统。[reference:11]
- **剧情定位**：艾利尔基地坠毁后，成为XIG的**临时基地**和最终决战的后方据点。特殊搜查队“Lizard”也隶属于此。[reference:12]

## 三、人间体变身器

### 1. 蓝宝锥（Esplender）

- **使用者**：高山我梦。
- **外形**：以盖亚胸口的**彩色计时器**为原型，三角形，金色边框，中心镶嵌可发光的蓝色光能量结晶。背面设有握把套，便于手持。[reference:13]
- **功能**：**本身无变身能力**，仅用于收纳和释放大地之光。内部的光电子管可储存光之力，变身的核心是我梦的意志与光的呼应。**这是奥特曼系列中第一个由人间体自行制作的变身器**。[reference:14]
- **变身动作**：右手握住握柄，置于左胸前，然后将蓝宝锥向前上方伸出。早期至中期通常保持沉默，第26话后更频繁地喊出“盖亚！”。
- **时序约束**：**第1话我梦尚未持有此道具**。变身依靠直接与大地之光融合。蓝宝锥是第3话前后由我梦亲手制作完成的。**AI不得让第1话的我梦掏出蓝宝锥。**

### 2. 蓝宝镯（Agulater）

- **使用者**：藤宫博也。
- **外形**：手镯状装置，佩戴于右手腕。形状与阿古茹的彩色计时器类似，闭合时两片翼状附加物收拢。
- **功能**：收纳海洋之光，在必要时解放光进行变身。
- **变身动作**：右臂向下伸展，蓝宝镯的翼状物向左右展开，发光部分闪烁青光，随后挥动手臂在胸前握紧拳头，蓝光包裹后完成变身。[reference:15]
- **来源**：官方设定中存在“海洋意志授予”与“藤宫自己制作”两种说法，叙事中保留这一模糊性。

## 四、XIG主力战机与载具

> **通用设定**：所有XIG战机均搭载由我梦开发的**Repulsor Lift（反重力浮场 / 引力排斥系统）**，通过推斥力升空，可在平流层中盘旋飞行。所有机体均具备**集装箱形态变形机构**（六棱柱型，全长9米），可收纳于艾利尔基地或Peace Carry中，在出击或投放后于空中迅速变形为战机形态。[reference:16][reference:17]

### 1. XIG Fighter SS（队长机）

- **使用者**：空中三队队长（梶尾、米田、稻城）。
- **外形与定位**：全长**14米**，乘员**2名**。性能最强的空战指挥节点。
- **最高速度**：**9马赫**（可在大气层及宇宙空间飞行）。[reference:18]
- **武器**：主武器为**斯派拉尔炮**；常规武装包括激光炮、导弹。
- **限制**：**无能量护盾**，会被击毁。第47话艾利尔基地坠毁时全毁。

### 2. XIG Fighter SG（队员机）

- **使用者**：空中三队普通队员。
- **外形与定位**：全长**11米**，乘员**2名**。平时以集装箱形态搭载于Peace Carry中，出击时变形。
- **最高速度**：**6马赫**。
- **武器**：机翼配备**HEAT导弹**、激光光束。可换装炸弹或液氮弹。

### 3. XIG Fighter EX（我梦专用机）

- **使用者**：高山我梦（第4话后成为专用机）。
- **外形与定位**：全长**12米**，乘员**2名**，主色调银色。侦察/电子战性格强。
- **最高速度**：**8马赫**。
- **特殊系统**：搭载我梦编程的人工智能**PAL**。**我梦变身为盖亚时，PAL可自动操作战机**，制造不在场证明。这是掩盖身份的关键技术支撑。第50话被佐格摧毁，PAL数据后续在我梦电脑中复原。[reference:19]

### 4. XIG Fighter ST / GT（后期机型）

- **部署时间**：第48话，艾利尔基地坠毁后部署于吉欧基地。
- **ST**：SS的改良型，全长14米，最高速度**12马赫**。性能极强，**全队仅米田队长能驾驭**。
- **GT**：SG的改良型，全长11米。梶尾和稻城各驾驶一架。具体马赫数资料未明确载明，以剧中表现为准。[reference:20]

### 5. Peace Carry（和平运输机）

- **定位**：XIG的大型移动指挥与运输攻击机。堤诚一郎常在此机上现场指挥，神山笃志担任主驾驶员。
- **外形与参数**：全长**36米**，乘员**10名**。机腹设有三个六边形投放舱（A/B/C）。
- **飞行速度**：**2马赫**。
- **武器**：最初无武装，后在机首配置**两门炮管**。可根据任务搭载导弹、火箭、炸弹。
- **载运能力**：**最多可搭载3架XIG Fighter SG（集装箱形态）** 或同级别战车/载具。[reference:21]
- **功能**：同时作为空中预警机使用。平时多于前线担当指挥任务，较少直接作战。

### 6. 地面/水面载具

- **贝尔曼车**：XIG巡逻用特种高速汽车，上部配备**激光加农炮**。
- **MLRS野牛**：海格力斯队三人座陆战越野车，配备穿甲弹、大炮和**多管火箭系统**。
- **GBT史丁号**：海格力斯队高性能机动战车，队伍全力武器。
- **箭鱼7500（Siren 7500）**：箭鱼队小型万能潜航艇，可在**深海10000米以下**行驶。由和平号投放。
- **海鸥漂游机**：海鸥队救援支持用陀螺机。

## 五、单兵武器与防护

### 1. 杰特枪（Jector Gun）

- **外形**：XIG队员日常佩戴的小型激光枪。
- **功能**：通过更换六角形的**HYPOP弹**改变功能。剧中已确认的功能包括：**激光（默认）、热线弹、麻醉弹**。最快可连续发射**10发**。**AI不得凭空扩展“冰冻弹”“穿甲弹”等未登场功能**。[reference:22]

### 2. XIG巴尔干

- **定位**：个人便携式爆破枪。
- **功能**：装有三门HYPOP弹，旋转枪管发射高破坏能量弹。**主要使用者为海格力斯队**（因重量大）。[reference:23]

### 3. XIG Combaits（战斗服）

- **材质与防护**：两件式结构（深蓝、灰、黄拼配夹克+灰色裤子）。具备**耐冲击、耐高温、耐低温、耐高压、防弹**性能，可在超高速战机驾驶舱内保护队员免受G力伤害。[reference:24]
- **颜色区分**：不同小队有专属臂章和头盔配色。闪电队纯白头盔；猎鹰队灰色带黄轮廓；酷龙队红色；海鸥队白色配海军蓝编号。
- **操作员制服**：非战斗人员（敦子、乔姬等）穿着**迷你裙式**两件式队服。全职队员内衣袖子为**黄色**，非全职（如鹈饲彩香）为**白色**。第33话中，乔姬在随我梦赴加拿大时曾穿着过Combaits。

### 4. XIG-NAVI

- **外形**：佩戴在**左手腕**上的腕表型超小型高性能电脑。
- **功能**：内置高性能中央处理器。**最常用功能是通信（视频电话）**，也支持数据分析和数字时钟。TV本篇中**不具备**内置Repulsor Lift悬浮、广域生物反应扫描等后续作品追加的高阶功能，AI不得混淆。[reference:26]

### 5. XIG头盔（XIGメット）

- **功能**：内置超小型高性能数码相机，轻量且坚固。不同小队有不同配色。我梦的头盔带有“00”编号和XIG徽章。

### 6. 移动终端（Mobile Machine）

- **设定**：我梦自制的专用高性能移动终端，可自由使用通信线路，使用体验极佳。[reference:28]

## 六、奥特曼形态数据与战术定位

### 1. 盖亚（高山我梦）

**V1**：身高**50米**，体重**42,000吨**。飞行**20马赫**，走行**5马赫**，水中**1马赫**，潜地**1.2马赫**，跳跃力**1,200米**，握力**50,000吨**。**基础战斗形态**。光线技能以**量子流线**为主，运用尚不熟练。
**V2**：第26话获得阿古茹之光后解锁。飞行**20马赫**，走行**5.5马赫**，水中**1.2马赫**，潜地**1.5马赫**，跳跃力**1,200米**，握力**70,000吨**。**力量提升到V1的两倍以上，可使用阿古茹的技能**（如光子粉碎机）。[reference:29]
**SV（至高型）**：第26话登场，V2最大解放后的最强形态。飞行**25马赫**，走行**7马赫**，水中**1.5马赫**，潜地**2马赫**，跳跃力**1,500米**，握力**120,000吨**。**全能力为V2的两倍，力量与光线为V2的数倍**。**维持时间仅1分钟**，消耗能量极大。格斗能力极强，摔跤术尤为出色。

### 2. 阿古茹（藤宫博也）

**V1**：身高**52米**，体重**46,000吨**。飞行**19马赫**，走行**5.5马赫**，水中**1.2马赫**，潜地**1.5马赫**，跳跃力**1,100米**，握力**60,000吨**。技能：光子粉碎机、阿古茹光刃。[reference:31]
**V2**：第41话海洋之光重新认可后解锁。飞行**23马赫**，走行**7.4马赫**，水中**1.5马赫**，潜地**1.8马赫**，跳跃力**1,300米**，握力**90,000吨**。技能：阿古茹流线、光子粉碎机（威力提升至2倍）。[reference:32]

### 3. 活动限制

盖亚与阿古茹在地球上**无活动时间限制**。无能量时彩色计时器从蓝变红闪烁，停止闪烁则无法站起。计时器被破坏会失去光芒，人间体一段时间内无法变身。**SV形态因能量消耗过大，维持时间仅1分钟。**

## 七、运行约束（科技侧硬规则）

1. **科技降级原则**：XIG是近未来防卫军。战机**没有能量护盾**，会被击毁；飞行员会受重伤；通讯会被干扰。AI不得写出“战机硬抗怪兽光线无伤”的情节。
2. **形态锁定原则**：第1话我梦只有V1，绝不能使用SV专属技能；藤宫在失去海洋之光期间绝不能变身。形态解锁必须严格对应第26话/第41话等锚点节点。
3. **基地限制**：剧情推进到艾利尔基地坠毁（第47话）后，所有XIG指挥与出动必须在**吉欧基地**或野外进行。AI不得再写“返回空中基地补给/休整”的情节。
4. **道具时序**：第1话我梦**没有蓝宝锥**。AI不得让第1话的我梦掏出蓝宝锥。
5. **设施细节原则**：描写艾利尔基地内部时，可以调用**私室（允许养宠物）、训练室、浴场、食堂、飞行模拟器**等日常设施，让基地具有“有人生活的空间”的质感，而不是一个纯粹的军事指挥中心。
